# Online Voting System

A web-based online voting platform developed using HTML, CSS, JavaScript, and Firebase.

## Features

- Secure voter authentication
- Online vote casting
- Real-time vote counting
- Voting results dashboard
- Firebase integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase

## Project Structure

├── index.html
├── vote.html
├── results.html
├── style.css
├── app.js
└── firebase.js
